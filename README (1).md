# Dados

O arquivo bruto `master.csv` não é versionado neste repositório para manter o Git leve e respeitar a distribuição da fonte.

## Como obter

1. Acesse o dataset [Suicide Rates Overview 1985 to 2016 no Kaggle](https://www.kaggle.com/datasets/russellyates88/suicide-rates-overview-1985-to-2016).
2. Faça o download e extraia o arquivo `master.csv`.
3. Coloque o arquivo nesta pasta, com o caminho `data/master.csv`.
4. Execute o notebook em `notebooks/analise_exploratoria.ipynb`.

O notebook valida a presença das colunas esperadas e informa se o arquivo ainda não foi colocado na pasta. Não inclua tokens, credenciais ou dados pessoais no repositório.
